### Готовский Геннадий Дмитриевич, Б05-305

### Датасет: Amazon Reviews 2023 — Software

Источник: Amazon Reviews 2023, категория **Software**  
https://amazon-reviews-2023.github.io/

Используются пользовательские оценки товаров, временные метки взаимодействий и метаданные объектов.

После удаления дубликатов и применения iterative 5-core фильтрации:

- **Interactions:** 1 276 840
- **Users:** 146 396
- **Items:** 17 591

Релевантным считается объект с оценкой

$$
r_{ui} \ge 4.
$$

### Реализованные модели

- Item-based Collaborative Filtering (ItemKNN)
- Explicit-feedback ALS
- EASE
- Factorization Machine (FM) с метапризнаками
- Custom-Signal ALS с временным целевым сигналом

Дополнительно используется **MostInteracted** как простой baseline.

### Оценка

Используется временное разбиение данных:

- **Train:** 80%
- **Validation:** 10%
- **Test:** 10%

Основная метрика выбора гиперпараметров — **NDCG@10**.

Дополнительно используется **Recall@10**. Для анализа моделей также рассчитываются **Coverage@10**, **Novelty@10**, **HitRate@10** и **MRR@10**.

Для всех моделей используется единый протокол оценки. Из множества кандидатов исключаются объекты, уже встречавшиеся пользователю в обучающей истории:

$$
C_u = I_{\text{train}} \setminus I_u^{\text{train}}.
$$

Все модели оцениваются на одинаковых разбиениях, пользователях, кандидатах и по одинаковым правилам оценки.
